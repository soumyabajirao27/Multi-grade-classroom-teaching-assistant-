# Demo video script (about 4 minutes)

1. **0:00 Problem (20 s)**: "One teacher, five grades, one period." Show a classroom photo or sketch.
2. **0:20 Plan (40 s)**: choose Water, select Grades 1, 3, 5. Point out the shared theme, the three different activities, the peer buddy for Grade 1.
3. **1:00 Worksheets (50 s)**: open Worksheets, show three difficulty levels, click New questions, show the answer key, press Print.
4. **1:50 Rotation (60 s)**: set 40 min, turn on Demo mode, start. Show the countdown, the beep, the highlighted row moving to the next grade, and a warning.
5. **2:50 Progress (40 s)**: add children, mark one "Needs help", return to Worksheets and show the new Support sheet.
6. **3:30 Offline + languages (20 s)**: switch to Hindi, turn on airplane mode, reload; the app still works.
7. **3:50 Close (10 s)**: results from the usability test and the reviewer score.
