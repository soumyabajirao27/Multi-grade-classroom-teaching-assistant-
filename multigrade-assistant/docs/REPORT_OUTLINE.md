# Project report outline

1. **Problem**: one teacher, 3-5 grades; why manual differentiation is not feasible. Add 2-3 facts about multi-grade schools in India with sources (e.g. UDISE+ data).
2. **Market gap**: mainstream ed-tech assumes one grade per class; compare 3-4 existing tools in a table.
3. **Users and requirements**: teacher persona, constraints (offline, low-end tablet, little time, multiple languages).
4. **Solution overview**: four modules with screenshots from the running app.
5. **Design**: architecture diagram (docs/ARCHITECTURE.md), data model, the seven differentiation rules and why each exists.
6. **Content and curriculum mapping**: how topics map to NCERT / state-board outcomes; the review process.
7. **Implementation**: stack, testing strategy, offline/PWA, privacy.
8. **Evaluation**: results of docs/EVALUATION.md sections A-C with tables and quotes.
9. **Limitations and future work**: more topics and languages, adaptive difficulty from results, voice instructions for Grades 1-2, shared tablets with sync.
10. **Appendix**: sample worksheets, SUS responses, reviewer scores, code structure.
